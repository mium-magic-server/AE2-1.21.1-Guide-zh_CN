# 末影驱动器！

末影驱动器专注于一种不同的物品存储方式。这些驱动器根据为每个驱动器设置的频率相互链接。所有具有相同频率和隐私设置的驱动器共享相同的内容，无论由谁制作。无论是在你的AE2系统中、另一个维度中，还是在其他玩家的系统中，内容都是全局同步的。
