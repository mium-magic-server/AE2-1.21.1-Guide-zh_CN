# 量子护甲套装



<Row gap="10">

<ItemImage id="advanced_ae:quantum_helmet" scale="4"></ItemImage>

<ItemImage id="advanced_ae:quantum_chestplate" scale="4"></ItemImage>

<ItemImage id="advanced_ae:quantum_leggings" scale="4"></ItemImage>

<ItemImage id="advanced_ae:quantum_boots" scale="4"></ItemImage>

</Row>



* <ItemLink id="advanced_ae:quantum_helmet" />

* <ItemLink id="advanced_ae:quantum_chestplate" />

* <ItemLink id="advanced_ae:quantum_leggings" />

* <ItemLink id="advanced_ae:quantum_boots" />



你是否曾想过穿上你的AE系统会是什么感觉？现在，你无需再猜测了。量子护甲套装是一款高科技潜行装备，它能连接到AE2系统，让你随时随地便捷地访问一切！默认情况下，它是一套能量驱动的护甲，其防御力可与下界合金装备相媲美。它能够利用其缓冲能量来生成能量护盾，提供可观的伤害吸收。靴子还能抵消摔落伤害，而胸甲则可以消除飞行时的挖掘速度惩罚。然而，这套护甲真正的力量只有在装满升级卡后才能解锁！



<br/>



## 连接护甲



护甲部件可以通过放入<ItemLink id="ae2:wireless_access_point" />的相应插槽中单独连接到系统。根据装备部件和安装的升级卡，这会解锁不同的增益效果。稍后会详细介绍。请注意，要使这些额外功能正常工作，你还需要处于所连接的无线访问点的范围内。



<br/>



## 安装升级



要安装升级，你需要先装备好护甲部件，然后按下快捷键（默认为N）打开量子护甲配置菜单。



![QAGUI](../pic/quantum_armor_config.png)



在此界面中，你可以添加/移除升级卡、启用/禁用它们，并为支持设置的升级卡配置选项。



<br/>



## 量子升级基础卡



<ItemImage id="advanced_ae:quantum_upgrade_base" scale="2"></ItemImage>



<ItemLink id="advanced_ae:quantum_upgrade_base" />本身没有特殊功能，但它被用作所有升级卡的合成材料。



<br/>



## 自动喂食卡



<ItemImage id="advanced_ae:auto_feeding_card" scale="2"></ItemImage>



<ItemLink id="advanced_ae:auto_feeding_card" />允许选择特定的物品来为玩家补充饥饿值。只需将所需物品拖入筛选槽中，如果装备已连接到AE2网络，它就会尝试在系统中找到这些物品，并在玩家饥饿时进行喂食。



<br/>



## 自动补货卡



<ItemImage id="advanced_ae:auto_stock_card" scale="2"></ItemImage>



<ItemLink id="advanced_ae:auto_stock_card" />同样要求装备部件连接到AE2系统并处于无线访问点的有效范围内。它允许配置若干组物品，使其在用户物品栏中始终保持特定数量。这些槽位不限于一组，因此如果你愿意，可以设置它们始终在物品栏中填充多个槽位。



<br/>



## 速度卡



<Row gap="10">

<ItemImage id="advanced_ae:walk_speed_card" scale="2"></ItemImage>

<ItemImage id="advanced_ae:sprint_speed_card" scale="2"></ItemImage>

<ItemImage id="advanced_ae:swim_speed_card" scale="2"></ItemImage>

</Row>



* <ItemLink id="advanced_ae:walk_speed_card" />

* <ItemLink id="advanced_ae:sprint_speed_card" />

* <ItemLink id="advanced_ae:swim_speed_card" />



这些升级卡提高了套装穿戴者的移动速度。它们都具有可配置的速度值，并且会影响潜行和飞行时的移动速度。需要注意的是，这些升级卡也可用于降低速度，以便在其他加速效果生效时获得更好的控制力。



<br/>



## 高度卡



<Row gap="10">

<ItemImage id="advanced_ae:jump_height_card" scale="2"></ItemImage>

<ItemImage id="advanced_ae:step_assist_card" scale="2"></ItemImage>

</Row>



* <ItemLink id="advanced_ae:jump_height_card" />

* <ItemLink id="advanced_ae:step_assist_card" />



这些升级改变了垂直移动能力，允许配置更高的跳跃高度或提供台阶辅助（跨步）功能。



<br/>



## 飞行卡



<Row gap="10">

<ItemImage id="advanced_ae:flight_card" scale="2"></ItemImage>

<ItemImage id="advanced_ae:flight_drift_card" scale="2"></ItemImage>

</Row>



### 飞行卡



安装<ItemLink id="advanced_ae:flight_card" />后，可启用创造模式飞行。飞行速度可以通过界面中的滑块进行配置。它还会受到移动/疾跑速度升级卡的叠加影响。



### 飞行惯性卡



<ItemLink id="advanced_ae:flight_drift_card" />仅在安装了飞行卡时生效，它会添加另一个配置滑块来改变影响创造模式飞行的惯性。较低的值会让你更快停止，当值设置为0时，你会立即停止。



<br/>



## ME无线充电卡



<ItemImage id="advanced_ae:recharging_card" scale="2"></ItemImage>



<ItemLink id="advanced_ae:recharging_card" />可为装备的部件启用无线充电功能。这需要连接到网络并处于无线访问点的范围内。将此升级安装在胸甲上还有一个额外的好处，即同时为物品栏槽位充电。



<br/>



## 便携式元件工作台卡



<ItemImage id="advanced_ae:portable_workbench_card" scale="2"></ItemImage>



<ItemLink id="advanced_ae:portable_workbench_card" />为量子套装添加了一个便携式元件工作台。要打开它，你需要按下配置的快捷键。它的工作方式与方块形式的元件工作台相同。



<br/>



## Pick-Craft功能卡



<ItemImage id="advanced_ae:pick_craft_card" scale="2"></ItemImage>



<ItemLink id="advanced_ae:pick_craft_card" />为护甲添加了一个新的快捷键功能。按下快捷键会尝试合成玩家当前瞄准的方块。此功能需要连接到网络，并且存在与目标匹配的样板。将会弹出一个窗口要求输入所需数量，其过程与普通的自动合成请求完全相同。



<br/>
