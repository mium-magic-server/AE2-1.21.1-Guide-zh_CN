# 内存卡

<ItemImage id="memory_card" scale="4" />

内存卡可用于在AE2[设备](../ae2-mechanics/devices.md)间复制粘贴设置，以及连接[P2P通道](p2p_tunnels.md)。它还可以将[升级卡](upgrade_cards.md)粘贴到设备中。

- Shift+右键点击以复制设置或生成新的P2P连接频率。
- 右键点击以粘贴设置、升级卡或连接频率。
