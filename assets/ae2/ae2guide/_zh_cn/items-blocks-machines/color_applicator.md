# 染色器

<ItemImage id="color_applicator" scale="4" />

染色器用于为可染色方块上色，例如[线缆](cables.md)、羊毛、陶瓦、玻璃和混凝土。它使用
[染色球](paintballs.md)或染料，雪球可用于清除线缆上的颜色和方块上的染色球污渍。

其能量可在<ItemLink id="charger" />中补充。

染色器的功能类似于[存储元件](storage_cells.md)，将其放入<ItemLink id="chest" />的存储元件槽位中即可轻松补充染色剂。

右键点击目标以应用所选颜色。要更改颜色，请在按住Shift的同时使用鼠标滚轮，或右键点击无目标区域。

## 升级

染色器支持通过<ItemLink id="cell_workbench" />安装以下[升级卡](upgrade_cards.md)：

*   <ItemLink id="equal_distribution_card" />为每种类型分配相同的存储字节空间，防止单一类型占满整个元件
*   <ItemLink id="void_card" />在元件已满时虚空掉多余物品（若安装了均分卡，则指该类型分配的特定空间）。使用时请注意分区！
*   <ItemLink id="energy_card" />可增加其电池容量
