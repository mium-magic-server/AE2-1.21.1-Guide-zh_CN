# 什么是应用能源2？

应用能源2添加了组件和机制，提供物流和存储解决方案。你可以用紧凑的ME网络取代装满箱子的大房间，但这只是开始。
应用能源旨在与整合包中的其他模组协同工作，并实现自动化。你可以设置系统，通过单次点击就能合成复杂合成链的所有前置条件（及最终产物），或者保持特定数量的物品库存，根据需要合成更多，或者简单地在基地中转移物品。
