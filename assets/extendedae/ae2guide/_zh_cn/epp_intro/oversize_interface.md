# ME超大接口

<BlockImage id="extendedae:oversize_interface" scale="8"></BlockImage>

ME超大接口具有与<ItemLink id="extendedae:ex_interface" />相同的槽位数，但每个槽位可容纳的物品数量是其16倍（可配置）。
这意味着每个槽位最多可容纳1024（64×16）个物品。

通过配置，其他模组中的特定物品可设置不同的倍率。
