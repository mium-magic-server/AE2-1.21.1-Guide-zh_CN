# 配置修改器



配置修改器是一种用于批量修改配置物品栏的工具。



<ItemImage id="extendedae:config_modifier" scale="4"></ItemImage>



右键点击可打开其图形用户界面。



## 使用方法



配置修改器可根据设置快速修改界面配置物品栏，例如将配置物品数量设置为最大值或直接清空所有配置。



手持配置修改器点击世界中的目标设备（方块或子部件）即可修改其配置。



## 设置选项



具有两个主要设置：**修改模式**和**修改数量(X)**。



点击按钮可切换模式。



![GUI](../pic/cm.png)



- 加/减/乘/除：将配置数量增加/减少/乘以/除以 X

- 最大化：将配置数量设置为最大值

- 最小化：将配置数量设置为最小值

- 设定：将配置数量设置为 X

- 清除：清空所有配置
